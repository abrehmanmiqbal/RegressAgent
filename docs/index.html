RegressAgent records how your AI agent behaved, then compares before and after a change. It catches regressions that a text check misses, such as an agent that silently stops calling a tool.

Try it in 2 minutes Release notes Source

The problem

A support agent used to look up the order before replying. After a prompt change it skips the lookup, but still says "Your order is on its way." The wording is identical, so a normal test passes. This is the real output of the bundled demo:

$ regressagent compare 1 2
verdict: regressed
  message                      equals           still_passing
  steps                        tool_called      regressed
  steps                        tool_not_called  still_passing
  steps                        tool_order       regressed
  steps.0.arguments.order_id   equals           still_passing

The message is still_passing, but the tool-call assertions are regressed. That is the whole idea.

What you get

  • 11 assertion operators

    Equality, regex (ReDoS-restricted), numeric, type, and tool-call checks: tool_called, tool_not_called, tool_order.

  • Real agents

    Run a local command, the same command inside a bubblewrap sandbox, or an HTTP endpoint.

  • Traces to cases

    Store traces (secrets redacted before disk) or import OpenAI and Anthropic conversations, then generate reviewable cases.

  • Dashboard and CLI

    A local web UI with health tiles, compare view and a command palette, plus a scriptable CLI with exit codes.

  • Offline first

    No cloud, no account, no paid API. Data stays in a local SQLite file.

  • Honest evidence

    782+ tests, mutation checks, fuzzing, and a log of what was and was not verified.

Try it

Not on PyPI yet, so install from the source (Python 3.11 or 3.12):

git clone https://github.com/abrehmanmiqbal/RegressAgent.git
cd RegressAgent
python3 -m venv .venv && source .venv/bin/activate
pip install -e .
regressagent demo
regressagent serve      # open the "Open the UI" link it prints

Windows: use WSL2 (not tested natively). Full instructions are in the README.

Security by default

  • The API and UI bind to loopback only, need a random token, and reject foreign Host/Origin headers.
  • Secrets are redacted before anything is written to the database.
  • Tier B runs your agent in a bubblewrap sandbox (no network, minimal read-only filesystem, no capabilities) and refuses to run unsandboxed if it cannot build one.
  • The HTTP adapter has an SSRF guard, pinned connections, no redirects and verified TLS.

Tier A (plain command) is not a sandbox. See the threat model for what is and is not covered.

Honest status

  • Alpha. Developed and tested on Linux; macOS and Windows are untested.
  • The UI is tested with a simulated DOM and (in the repo's browser test) Chromium on machines that have it. It had not been opened in a real browser by its author when v0.1.0 was cut.
  • Importers were tested on hand-written conversations, not real exports.
  • Built with AI assistance; every claim above is backed by a test or a recorded command in the repo.
